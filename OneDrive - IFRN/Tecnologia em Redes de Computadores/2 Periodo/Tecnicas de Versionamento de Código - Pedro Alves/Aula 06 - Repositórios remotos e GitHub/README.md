#Exercício 06 - Repositório Remotos e GitHub

## Descrição
Projeto prático desenvolvido para a disciplina de Técnicas de Versionamento de Código (IFRN), focado no aprendizado de repositórios remotos e integração com o GitHub.

## Como Executar o Projeto
1. Clona o repositório:
   `git clone git@github.com:cebaspc/exercicio-06-git.git`
2. Acede à pasta do projeto:
   `cd exercicio-06-git`
